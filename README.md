\# HealthApp



Aplicación móvil para la gestión de pacientes.



\## Objetivo

Facilitar la gestión de información de pacientes mediante una aplicación móvil.



\## Módulos

\- Inicio de sesión

\- Registro de pacientes

\- Configuración del sistema



\## Inicio de sesión

El sistema permitirá a los usuarios acceder mediante sus credenciales.



\## Registro de pacientes

El sistema permitiría registrar la información básica de los pacientes.
